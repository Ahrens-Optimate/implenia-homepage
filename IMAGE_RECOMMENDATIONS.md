## How to Implement

Once you select images:

1. **Download** high-resolution versions
2. **Optimize** using TinyPNG or Squoosh
3. **Replace** the current image:
   ```bash
   # Replace hero background
   cp new-hero-image.jpg src/assets/images/hero-background.jpg

   # Replace problem section
   cp new-problem-image.jpg src/assets/images/problem-section.jpg
   ```
4. **Refresh** browser to see changes (Astro auto-optimizes)
