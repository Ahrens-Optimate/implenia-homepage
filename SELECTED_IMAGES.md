## How to Purchase and Implement

### Step 1: Purchase Images
1. Go to https://photodune.net
2. Create account or log in
3. Purchase both images (add to cart, checkout)
4. Download the full-resolution, unwatermarked versions

### Step 2: Replace Preview Images
After downloading from Envato:

```bash
# Replace hero background
cp ~/Downloads/39405216_oresund_bridge.jpg implenia-ahrensoptimate/src/assets/images/hero-background.jpg

# Replace problem section
cp ~/Downloads/24002134_engineers_blueprints.jpg implenia-ahrensoptimate/src/assets/images/problem-section.jpg
```

### Step 3: Optimize Images (Optional but Recommended)
Use TinyPNG or Squoosh to reduce file size without quality loss:
- Target: <500KB for hero, <200KB for problem section
- Format: JPG quality 85-90%
- Astro will auto-convert to WebP for modern browsers

### Step 4: Verify
Refresh the dev server and verify watermarks are gone.
